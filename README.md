# Weather Forecast Application 🌦️

A web app built with HTML, CSS and JavaScript that shows the current temperature and weather conditions for a searched city using the OpenWeatherMap API.

**Live Demo:** https://ranjith937.github.io/Weather-Forecast-Application/

## Features

- Search by city name using the button or Enter key
- Current temperature (°C) and weather description
- Weather icon and color that change with the temperature
- Five tips suited to the temperature range
- Shows Hyderabad's weather by default
- Alert when the city lookup fails

## Tech Stack

- HTML, CSS, JavaScript
- Fetch API with async/await
- OpenWeatherMap API
- Font Awesome and Google Fonts

## Project Structure

```
├── index.html   # Page structure
├── index.css    # Styling
├── index.js     # API call and page updates
└── README.md
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Ranjith937/Weather-Forecast-Application.git
   ```
2. Get an API key from [OpenWeatherMap](https://openweathermap.org/).
3. In `index.js`, replace the value after `appid=` with your key.
4. Open `index.html` in your browser.
